# Archive

These files are historical records of how DarkFactory was specified, tracked and assessed during v0.1–v0.2. They are **not instructions**: commands, paths, tools, scores and policies in them may no longer be true. Links that pointed at moved or deleted docs were redirected to their current successors. [AGENTS.md](../../AGENTS.md) and the current docs always win.

| File | What it was |
| --- | --- |
| `MASTER_PROMPT.md` | The original one-shot build prompt |
| `specs/DARKFACTORY_SPEC.md`, `specs/DARKFACTORY_ONE_SHOT_PROMPT.md` | The v0.1 specification and generation prompt |
| `evidence-map.md` | The v0.1–v0.2 requirement-to-evidence ledger |
| `TODO.md` | The post-v0.2 hardening backlog |
| `assessments/openssf-passing-evidence.md` | Evidence recorded for the OpenSSF Best Practices passing badge |
| `assessments/agent-friendly-*.json` | Agent Friendly Code assessments (scores are stale) |

Do not edit these files except to fix Markdown lint. Record new decisions in [ARCHITECTURE.md](../../ARCHITECTURE.md#decisions) or `docs/adr/`.
